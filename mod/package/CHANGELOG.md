# Changelog

## 0.9.1

- Preview GIFs on the mod page.

## 0.9.0
- First public beta.
- Elemental status effects drawn on the creature's skin: char and flames for fire, frost crust and cracks, poison veins and bubbles, lightning arc bursts, a hollow spirit rim.
- A few particles from the creature's own surface (the game's flames, embers, frost flakes, drips, sparks, wisps) and one shared light per creature.
- Ten element-pair combos and a special effect when all five elements are on one creature (Ragnarok), each with its own toggle.
- 136 settings, applied live when the config file is saved.
- Quiet mode: keep the vanilla effects, just smaller.
